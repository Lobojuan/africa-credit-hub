# Outreach Compliance Memory

Use this as a working checklist for CRM/GTM features and campaign copy.

## Email

- Store source/provenance for every lead and contact.
- Verify emails before outreach when possible.
- Use accurate sender identity.
- Use non-deceptive subject lines.
- Include a physical postal address when sending commercial email.
- Include unsubscribe/opt-out.
- Honor suppression/unsubscribe before any send.
- Keep audit history of AI drafts, human approvals, and sent messages.

## Phone

- Start with AI call prep and human call notes.
- Do not build autonomous AI cold calling in MVP.
- Store phone source/provenance and verification status.
- Keep notes, consent status, and follow-up tasks.

## AI

- AI may draft, summarize, classify, and recommend.
- Humans approve first external outreach.
- Local LLM output is advisory and must be checked before external use.
- Do not store secrets, private credentials, or API keys in memory.
